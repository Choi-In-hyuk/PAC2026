# car door 방문점 후보 세트 — 점 접촉 커버리지 우선, 중복 점 제거 안 함, 배치 방향 0°(영역 기본 방향)

작성: 김재연, 2026-10-08. 폴더 이름 `car_door_pointcover_noprune_dir0`:
- `pointcover`: 커버리지를 **각 점에서 공구를 멈춰 댔을 때 닿는 면적만으로** 셌다. 점 사이를 쓸고 지나간다는 가정이 없어서 **방문 순서를 어떻게 바꿔도 커버리지가 줄지 않는다.**
- `noprune`: 중복 점 제거를 하지 않았다. 점이 많고 겹침이 크다. **점을 고르는 일(set cover 등)은 받는 쪽에서 한다.**
- `dir0`: 점을 놓은 배치 격자의 줄 방향. 같은 설정으로 방향만 다른 `car_door_pointcover_noprune_dir90` 와 짝이다. 두 세트는 점 위치가 다르다(dir90 점 중 dir0 점과 1 mm 안에 겹치는 것 26%).

배열 키·dtype·shape 는 이전 전달분(`car_door`, v2.6)과 같다. `metadata.json` 에 `tool_cell`(공구·셀 조건)과 `coverage` 항목이 늘었다.

## 이전 전달분(v2.6)과 다른 점

| | v2.6 (`car_door`) | 이 세트 |
|---|---|---|
| 커버리지 기준 | 같은 줄 이웃 점 사이를 쓸고 지나간다고 보고 셈 | 점의 정지 자세 접촉만 셈 |
| 중복 점 제거 | 함(쓸고 지나감 가정으로 지움) | 안 함 |
| 패드 압입량 | 0.5 mm | 중심 접촉 0.5 mm, 가장자리 접촉 1 mm |
| 빈틈 보완 | 목표 98% | 목표 100%, 빈틈 이웃 탐색 추가 |
| 방문 목표 수 | 1,220 | 2,917 |
| 점 접촉만으로 센 커버리지 (면 중심, 면적 가중) | 83.5% | **99.41%** |

v2.6 은 줄 순서대로 쓸고 지나가는 것을 전제로 점을 지웠기 때문에, 순서를 바꾸면 커버리지가 떨어졌다(점 접촉만으로는 83.5%). 이 세트는 그 전제를 없앴다.

## 파일

| 파일 | 내용 |
|---|---|
| `surface_points.npz` | 표면점별 배열(아래 표). 행 i 는 모든 배열에서 같은 점 |
| `mesh.npz` | 작업물 메시(vertices, faces), 면별 영역 `face_region_ids`, 면별 상태 `face_status`, 원본 STL 삼각형 번호 |
| `regions.json` | 영역별 점 번호(`point_indices`), 접촉 방식, 선택 키, 공통 키, 넓이 |
| `metadata.json` | 단위, 좌표계 정의, `T_B_W`·`T_W_B`·`T_L_C`, 로봇 모델, 상태 코드표, 가정값 |

## 바로 쓰는 법

```python
import json, numpy as np
P = np.load("surface_points.npz")
meta = json.load(open("metadata.json", encoding="utf-8"))

m = P["tool_pose_valid"] & P["accessibility"]   # 방문 목표 행
pos_W = P["tool_positions"][m]                    # (K,3) 공구 프레임 C 원점 위치, W 좌표, m
R_W_C = P["tool_rotations"][m]                    # (K,3,3) 공구 프레임 C 의 회전, W 기준

T_B_W = np.array(meta["T_B_W"])                   # W -> 로봇 베이스 B
pos_B = (T_B_W[:3, :3] @ pos_W.T).T + T_B_W[:3, 3]
R_B_C = T_B_W[:3, :3] @ R_W_C
# 쿼터니언(xyzw): scipy.spatial.transform.Rotation.from_matrix(R_B_C).as_quat()
```

- **행 순서는 방문 순서가 아니다.** 순서는 경로 생성 쪽에서 정한다.
- 영역별로 나누려면 `P["region_ids"]` 또는 `regions.json` 의 `point_indices`. 영역마다 접촉 방식(중심/가장자리)과 공통 키가 하나다.
- 접근 불가·미검사 점도 배열에 남아 있다(`status` 로 구분). 이 행의 공구 위치·회전은 NaN 이다.

## 좌표계

- **W**: 입력 STL 좌표계, 단위 m. `points`, `normals`, `tool_positions`, `tool_rotations` 모두 W 표현.
- **C (공구 프레임)**: 원점 = 패드(디스크) 접촉면 중심. **z_C 는 공구축 방향으로 플랜지(로봇) 쪽**, 즉 표면 바깥을 향한다. 회전행렬은 열벡터 규약 `p_W = R_W_C p_C + t_W_C`.
  - "EE z 축이 표면을 누르는 방향(-법선)" 규약을 쓰면 R_W_C 에 x 축 180° 회전(diag(1,-1,-1))을 오른쪽에 곱한다.
  - 가장자리 접촉이면 원점(디스크 중심)은 표면점이 아니고 디스크 반지름만큼 떨어져 있으며, 공구축이 법선에서 5~45° 기울어 있다. 법선만으로 자세를 다시 만들지 말고 `tool_rotations` 를 그대로 쓴다.
- **L**: panda_link8(플랜지). `T_L_C` = 플랜지에서 공구 프레임까지 고정 변환(0.11 m, z 반전). 목표를 플랜지로 주려면 `T_B_L = T_B_C · inv(T_L_C)`.
- **B**: 로봇 베이스. `T_B_W` 는 이 데이터를 계산할 때 쓴 값이다. 실제 셀 배치가 다르면 김재연 쪽에서 그 값으로 다시 계산해야 한다(공구 자세의 로봇 도달 판정이 바뀜).

## 방문점을 만든 방법

1. 작업 면을 형상·공구·로봇 조건으로 영역을 나누고, 영역마다 공구 대는 방식(중심 접촉 / 가장자리 접촉)과 기울기 방향을 정한다(v2.6 과 같음).
2. 영역마다 배치 격자 줄을 긋고 줄 위 5 mm 마다 점을 놓는다. 줄 간격은 접촉 영역 폭이며, 아직 덮이지 않은 경계 바로 옆에 다음 줄을 놓는다. "덮였다"는 판단은 점의 정지 자세 접촉 영역만으로 한다. 줄 방향은 0°(영역 기본 방향).
3. 빈틈 보완: 덮이지 않은 곳이 가장 많이 모인 자리부터 점을 더한다(목표 100%, 그 자리 자세가 검사에 실패하면 포기).
4. 빈틈 이웃 탐색: 3에서 포기한 자리를, 반경 5 cm 안 다른 위치의 다른 기울기 방향·접촉 방식 자세로 덮어 본다(공구만 본 자세가 그 자리를 덮는 경우만 공구+로봇 검사).
5. 모든 방문점은 공구 충돌과 Panda IK(관절 한계·자기충돌·작업물 충돌·특이점)를 통과했다. 중복 점은 지우지 않았다.
6. 면 상태: 각 면은 같은 형상 영역에서 25 mm 안의 가장 가까운 점의 상태를 받는다. 25 mm 안에 점이 없어 "미검사"로 남은 면 중 검사를 통과한 자세의 접촉 영역이 덮는 면은 "작업 가능"으로 표시했다(이 세트 113개(28.5 cm²)). 접촉 폭이 넓어 줄 간격이 50 mm 를 넘는 곳에서 생긴다.

## 커버리지 계산 방법

1. 공구 자세 하나가 닿는 범위: 반지름 5 cm 평판 디스크 안에 있고, 패드 면에서 압입량(중심 접촉 0.5 mm, 가장자리 접촉 1 mm) 이내인 표면(Schneyer 2023 III-C 접촉 영역).
2. 점 하나가 닿는 범위의 표본점 횟수를 1 올린다(점 사이 이동은 세지 않음).
3. 커버리지 = 작업 가능 면 중 1회 이상 닿은 넓이 ÷ 작업 가능 면 넓이. 중첩 = 2회 이상 닿은 넓이 ÷ 1회 이상 닿은 넓이.

압입량 근거(가정값): 로봇 연마 공구의 일반 누르는 힘 10~40 N(FerRobotics AOK), 인터페이스 패드 폼 두께 5~13 mm(Festool, 3M), 폼 탄성계수 14~300 kPa(가정 범위)로 패드를 얇은 탄성층으로 보고 계산하면 가장자리 접촉(기울기 5°)은 0.93~9 mm, 중심 접촉은 0.002~0.9 mm 다. 가장자리 1 mm 는 이 범위에서 보수적(작은) 값이다. 단단한 패드(탄성계수 1 MPa 이상)면 다시 봐야 한다.

## 받는 쪽에서 점을 고를 때 (권장)

- **set cover 로 점을 고를 때는 면 중심점(약 5 mm 간격)이 아니라 약 2 mm 간격 표본으로 고른다.** 면 중심으로 99% 를 맞추면 촘촘한 표본에서는 93~95% 로 떨어졌다(면 중심 사이 좁은 빈틈을 못 봄). 접촉 영역은 위 "커버리지 계산 방법" 1번 규칙으로 계산한다(접촉 방식은 `contact_modes`).
- 이전 압입량 1 mm 세트에서 2 mm 표본 greedy set cover 로 99% 를 맞추면 약 600~730개가 남았다(별도 표본 98.5% 안팎). 이 세트에서는 다시 확인이 필요하다.
- 행 순서·`line_ids` 는 방문 순서가 아니다. 순서는 경로 생성 쪽에서 정한다.

## 주의

- 공구 치수, 패드 압입량, 로봇 베이스 위치(작업면 중심 + (0.7, 0, 0) m, 회전 없음), 공구 장착 길이, door 단위는 가정값이다(`metadata.json` 의 `assumptions`, `tool_cell`). 공구 조건이 정해지면 다시 계산해서 보내며 배열 키·형식은 같고 값만 바뀐다.
- 커버리지는 "닿았나"이고 "충분히 깎였나"가 아니다. 접촉 영역 바깥 경계는 압력이 0 에 가깝다.
- 실제 경로의 점 사이 이동 중 공구 충돌·로봇 자세는 검사하지 않았다(점에서만 검사).
